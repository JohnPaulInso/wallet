================================================================================
  THE BUG
================================================================================

PROBLEM:
  User clicks "Complete Summary" → summary buttons appear
  User accidentally clicks "New Chat" button
  Result: Summary buttons + suggestion chips both visible (cluttered UI)

CAUSE:
  The startNewSession() function cleared messages but didn't reset:
    • summaryFlowActive flag
    • summaryFlowStep counter
    • summaryData object
    • currentButtonContainer DOM element

IMPACT:
  • Confusing UI
  • Buttons overlapping
  • Input bar might be hidden
  • User doesn't know what to do

================================================================================
  THE FIX
================================================================================

UPDATED 4 FUNCTIONS:

1. startNewSession()
   • Reset summaryFlowActive = false
   • Reset summaryFlowStep = 0
   • Clear summaryData
   • Remove button container
   • Clean state

2. switchSession()
   • Same reset logic
   • When switching conversations

3. closeChat()
   • Same reset logic
   • When closing AI overlay
   • Ensure input bar visible

4. clearUIPanel()
   • Call showInputBar()
   • Ensure input visible

LINES CHANGED: ~30 lines added
FILES MODIFIED: wallet-ai.js only
