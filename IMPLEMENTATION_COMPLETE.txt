================================================================================
  TECHNICAL DETAILS
================================================================================

State Management:
  • summaryFlowActive - Tracks if flow is active
  • summaryData - Stores user selections
  • currentButtonContainer - Manages button UI
  • abortController - Enables stopping responses

Key Functions:
  • startSummaryFlow() - Initiates the flow
  • handleSummaryTypeSelection() - Processes type choice
  • askTimeRange() - Shows time range buttons
  • handleTimeRangeSelection() - Processes time choice
  • generateAndSendSummary() - Constructs & sends prompt
  • showSummaryButtons() - Creates button UI
  • transformSendButtonToStop() - Changes button to stop
  • transformStopButtonToSend() - Changes button to send
  • stopAIResponse() - Aborts fetch request
  • callGeminiWithAbort() - API call with abort support

Architecture:
  • Modular, single-responsibility functions
  • Proper state management
  • Clean separation of concerns
  • Easy to extend with new types/ranges

→ Check Atome/Income exclusions working

→ Or clear localStorage for testing
→ Check reset time in error message
